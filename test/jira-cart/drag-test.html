The checklist


    
  
  1. Drop A on this page's sink. Confirm all four types arrive and
    that text/uri-list has the full four lines — and read the
    during dragover pair above it: types should list our
    marker while getData returns "". That pair is the
    document guard's whole mechanism.
    2. 
  
  2. Drop A on the tab strip, in the empty space right of the last
    tab. How many tabs opened? Four, or one? If one — which URL was it, the
    first or the last?
    3. 
  
  3. If step 2 gave one tab, drop C there, then D. Either changing
    the answer tells us the plain text or the line ending was the problem.
    4. 
  
  4. If step 2 gave one tab and it was a search rather than an issue,
    drop B there. That says plain text won over the URL list.
    5. 
  
  5. THE ONE THAT DECIDES THE BOOKMARKS HALF. Make an empty
    folder on the bookmarks bar, name it anything, and drop A
    onto the folder itself — not beside it. How many bookmarks landed
    inside, and what are they named? Chromium's clone loop targets the folder
    when the drop location says on, so this is the shipping design:
    you own the folder, the Cart fills it. A named folder cannot be created by a
    drop at all, from any web page — that is settled, not being tested here.
    6. 
  
  6. Make a tab group by hand, then drop A onto a tab
    inside it. Did what opened join the group? Same trade as the
    folder: dropping into a group you already made works, making a new one does
    not.
    7. 
  
  7. Drop A on the bookmarks bar itself, beside the folder. How
    many bookmarks appeared, and what are they named? This is the fallback
    behaviour, not the design — worth knowing, not worth building on.
    8. 
  
  8. Drop A into Teams' message box. Did it arrive as a list of
    live links?
    9. 
  
  9. Drop A into Notepad. Which of the three types won?
    10. 
  
  10. Drop E — the single-URL control — on the tab strip and the bookmarks
    bar. This is the shape that already works today for one row, so if it
    misbehaves the rig is at fault, not the design.
    11. 
  
  11. The hazard: drop A onto an ordinary web page. Did the
    tab navigate away, or did a new tab open?
    12. 
  
  12. THE ONE THAT DECIDES THE GUARD. Drop E — the
    single URL — onto an ordinary web page. Did the page you were on navigate
    away, or did a new tab open? Those are two different hazards. A new tab
    is a nuisance you close. Navigating away loses the page you were collecting
    from, which is the cost §2.9.1 accepted in writing, and it would still be
    live for the item drag that ships today.
    13.
